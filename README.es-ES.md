

# Curso de japonés N5–N1

Un curso interactivo de japonés gratuito y autónomo, desde cero hasta el nivel N1 del JLPT.
**Sin instalación. Sin cuenta. Solo abre `index.html` en cualquier navegador.**

🔗 **En línea:** [alanfwilliams.github.io/jlpt](https://alanfwilliams.github.io/jlpt)

---

## Qué incluye

| Característica | Detalles |
|---|---|
| **Plan de estudios N5 + N4 + N3 + N2 + N1** | N5 completo (365 días) + N4 (295 días) + N3 (300 días) + N2 (360 días) + N1 (400 días) — 1 720 días en total |
| **Repetición espaciada (SRS)** | Algoritmo SM-2, igual que Anki: las tarjetas se programan automáticamente |
| **Síntesis de voz (TTS)** | Voz japonesa nativa del navegador para cada palabra del vocabulario |
| **Ejercicios de comprensión auditiva** | Escucha una palabra y selecciona su significado |
| **Modo cuestionario** | Selección múltiple y escritura: el contenido de la lección se desenfoca para evitar trampas |
| **Progreso guardado** | localStorage: tu avance se recuerda entre sesiones |
| **Orden de trazos de kanji** | Opción para mostrar/ocultar diagramas de trazos (kanji de N5 y en expansión) |
| **Modo sin conexión** | Funciona sin internet después de la primera carga |

## Cómo usarlo

1. Abre `index.html` en Chrome, Edge o Safari (Firefox funciona, pero la calidad de la síntesis de voz puede variar)
2. Estudia el contenido del día
3. Haz clic en **Iniciar cuestionario** para probarte
4. Usa la pestaña **Repaso** a diario para las tarjetas de repetición espaciada
5. Haz clic en **✓ Marcar como completado** cuando termines

## Publicación en GitHub Pages

```bash
git init
git add index.html README.md
git commit -m "Initial commit: N5/N4/N3/N2/N1 1720-day course"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/jlpt-n5.git
git push -u origin main
```

Luego, en tu repositorio: **Settings → Pages → Source: Deploy from branch → main / root → Save**

Tu sitio estará en línea en `https://YOUR_USERNAME.github.io/jlpt-n5` en menos de un minuto.

## Resumen del plan de estudios

### Curso N5 (Días 1–365)
- **Días 1–14** — Hiragana (los 46 caracteres)
- **Días 15–28** — Katakana (los 46 caracteres)
- **Días 29–84** — Fundamentos (números, partículas, oraciones básicas)
- **Días 85–140** — Vocabulario central de N5 (~200 palabras)
- **Días 141–182** — Verbos esenciales (forma て, forma ます, conjugación)
- **Días 183–252** — Patrones gramaticales (partículas, condicionales, keigo)
- **Días 253–308** — Kanji (todos los ~100 kanji de N5)
- **Días 309–365** — Repaso y preparación para el examen JLPT N5

### Curso N4 (Días 366–660)
- **Días 366–395** — Repaso de N5 y gramática de transición (30 días)
- **Días 396–455** — Vocabulario de N4 (~300 palabras)
- **Días 456–500** — Verbos de N4 (extensiones de la forma て, potencial, pasivo, causativo)
- **Días 501–555** — Patrones gramaticales de N4
- **Días 556–620** — Kanji de N4 (~175 kanji)
- **Días 621–660** — Repaso y preparación para el examen JLPT N4

### Curso N3 (Días 661–960)
- **Días 661–690** — Repaso de N4 y transición a N3 (30 días)
- **Días 691–770** — Vocabulario de N3 (~1 500 palabras)
- **Días 771–820** — Verbos y adjetivos de N3 (transitivos/intransitivos, verbos compuestos, formas de conjugación)
- **Días 821–895** — Patrones gramaticales de N3 (~120 patrones)
- **Días 896–930** — Kanji de N3 (~170 kanji)
- **Días 931–960** — Repaso y preparación para el examen JLPT N3

### Curso N2 (Días 961–1320)
- **Días 961–990** — Repaso de N3 y transición a N2 (30 días)
- **Días 991–1090** — Vocabulario de N2 (~3 000 palabras: negocios, derecho, ciencia, medicina)
- **Días 1091–1140** — Verbos y expresiones de N2 (verbos compuestos, honoríficos, modismos)
- **Días 1141–1230** — Patrones gramaticales de N2 (~180 patrones)
- **Días 1231–1275** — Kanji de N2 (~200 kanji: gobierno, economía, ciencia)
- **Días 1276–1320** — Repaso y preparación para el examen JLPT N2

### Curso N1 (Días 1321–1720)
- **Días 1321–1350** — Repaso de N2 y transición a N1 (30 días)
- **Días 1351–1470** — Vocabulario de N1 (~4 000 palabras: formal, académico, literario, modismos)
- **Días 1471–1530** — Verbos y expresiones de N1 (verbos literarios, restos clásicos, dominio del keigo)
- **Días 1531–1640** — Gramática de N1 (~220 patrones: formal, clásica, literaria)
- **Días 1641–1690** — Kanji de N1 (~300 kanji: literario, formal, poético, médico, virtudes)
- **Días 1691–1720** — Repaso y preparación para el examen JLPT N1
